# Registration Form React App

This is a simple Registration Form project built using React JS.  
Users can enter their Name, Email, and Password to register.  
After successful registration, the registered users list is displayed on the screen.

---

## Features

- User Registration Form
- React Hooks (`useState`)
- Display Registered Users
- Success Message after Registration
- Simple and Clean UI

---

## Technologies Used

- React JS
- CSS
- JavaScript
- Vite
